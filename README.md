# Project_Skypro

Проект содержит модуль processing:
1) filter_by_state - Фильтрация списка словарей по значению
Принимает на вход 2 параметра:
        - data - список словарей
        - state - критерий сортировки (строка, опционально)
2) sort_by_date - Сортировка списка словарей по дате
Принимает на вход 2 параметра:
        - data - список словарей
        - descending - направление сортировки (True|False, опционально)
3) Написаны тесты ко всем функциям проекта
4) Модули тестируются в отдельных тестовых файлах.
5) При запуске тестов командой pytest все тесты завершаются успешно
6) Создал фикстуры
